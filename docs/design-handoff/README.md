## ما تغيّر في التصميم، ولماذا

| قبل | بعد | السبب |
| --- | --- | --- |
| شريط جانبي بتدرج أخضر + إيموجي لكل عنصر | لون صلب `#0F3D24` مع نقطة حالة، وأربع مجموعات معنونة (العمل اليومي، قواعد المعرفة، الفرص، الشركة، المنصة) | 11 عنصراً بلا تجميع يصعب مسحها؛ والإيموجي يختلف رسمه بين الأنظمة |
| رؤوس جداول خضراء صلبة `th { background: var(--primary) }` | رأس فاتح `#FAFCFA` بنص رمادي | التباين العالي في الرأس يسحب العين بعيداً عن البيانات |
| خط واحد لكل شيء | Noto Kufi Arabic للعناوين، IBM Plex Sans Arabic للنص، IBM Plex Mono للأرقام اللاتينية | الأرقام في جداول الأسعار تحتاج عرضاً ثابتاً للمحاذاة |
| بلا شريط علوي | شريط 58px: عنوان الصفحة، مُبدِّل الشركات، بحث، زر «إنشاء عرض جديد» | مكان ثابت للإجراء الأساسي وتبديل الشركة |
| `--radius: 14px`, حشوة 22px | `--radius: 11px`, حشوة 15–18px | كثافة أعلى تُظهر صفوفاً أكثر دون ازدحام |

الألوان لم تتغير: `#175934` / `#2E9E5B` / `#C6E5D1` كما في الملف الأصلي، مع إضافة `--primary-deep: #0F3D24` للشريط الجانبي و `--accent-soft: #EDF5EF` للوسوم.

## ثلاث مصائد واجهتها — لا تكررها

**١. الخط الأحادي يكسر العربية.** `IBM Plex Mono` بلا تغطية عربية، فأي نص عربي فيه ينفصل حرفاً حرفاً: «12 أغسطس» تصبح «12 أ غسطس». استخدم `var(--font-mono)` على الأكواد والأرقام اللاتينية فقط (`PR-2026-041`, `CV-010`, `1,240.00`)، وللأرقام داخل نص عربي استخدم `.num-cell` (خط عربي + `font-variant-numeric: tabular-nums`).

**٢. النص اللاتيني داخل حاوية RTL ينقلب.** «United Co.» تظهر «.United Co». لُفّ كل تتابع لاتيني في `<span dir="ltr">`.

**٣. الجداول متعددة الأعمدة.** لا تخلط أعمدة `px` ثابتة مع `fr` بلا حد أدنى — الأعمدة النصية تنكمش إلى صفر عند الشاشات المتوسطة. استخدم `minmax(140px, 2fr)` وأبقِ `.t-wrap { overflow-x: auto }` كما هو في الملف الأصلي.

## الخطوط

أضف في `<head>` قبل `styles.css` (أو أبقِ `@import` الموجود في أعلى الملف):

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Kufi+Arabic:wght@400;500;600;700&family=IBM+Plex+Sans+Arabic:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap" rel="stylesheet">
```

للنشر خلف جدار أو بلا إنترنت: نزّل الخطوط إلى `app/static/fonts/` واستبدل `@import` بقواعد `@font-face`.

## الأصول

`assets/azoom-mark-sq.png` — الشعار الرسمي مقصوصاً من الصورة التي أرسلها العميل، 480×480 بخلفية بيضاء. يوضع داخل `.brand .logo` (مربع أبيض 40px). **اطلب من العميل نسخة SVG أو PNG بخلفية شفافة** لوضعه مباشرة على الخلفية الخضراء بلا مربع، ولاستخدامه في ترويسة تصدير Word في `app/export_docx.py`.

## ترتيب التنفيذ المقترح

1. استبدال `styles.css` + إضافة الخطوط → يعطي أغلب التغيير البصري بلا لمس أي منطق.
2. تعديلات الماركب في `index-html-changes.md` (الشريط العلوي، مجموعات القائمة، كلاسات خلايا الجدول).
3. صلاحيات الأدمن — `admin-permissions.md`.
4. تعدد الشركات — `backend-multitenancy.md`، وهي الأكبر: ترحيل قاعدة بيانات + طبقة عزل.
